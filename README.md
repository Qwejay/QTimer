# ⏱️ QTimer - 极简流线型桌面悬浮计时器

![Python Version](https://img.shields.io/badge/Python-3.7+-blue.svg)
![PySide6](https://img.shields.io/badge/PySide6-Supported-brightgreen.svg)
![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20macOS-lightgrey.svg)
![High DPI](https://img.shields.io/badge/High%20DPI-4K%2F2K%20Ready-ff69b4.svg)
![Portable](https://img.shields.io/badge/Portable-Supported-orange.svg)

**QTimer** 是一款专为**说课、答辩、演讲、会议**等场景打造的桌面悬浮倒计时工具。它采用极简的无边框半透明设计，平时安静地悬浮在屏幕角落，鼠标悬停时如丝滑拉开的抽屉般展示控制面板。

## [1.6.1] - 2026-11-25

### 修复 (Fixes)
- 修复更换 Windows 桌面背景后，PPT / WPS 全屏放映时计时悬浮窗无法保持最前显示的问题。
- 增加放映期间窗口置顶状态的周期性恢复，避免窗口层级被系统改变。
- 修复 PPT 放映期间全局重置快捷键（Ctrl + Enter）失效的问题。
- 修复快捷键重置、上一环节和下一环节与 PPT 自动计时联动行为不一致的问题。

### 优化 (Improvements)
- 默认关闭「放映时暂停全局热键」，允许在 PPT / WPS 全屏放映期间直接使用全局快捷键。
- 增加配置版本迁移，升级后自动调整旧版热键设置，同时保留用户手动控制选项。
- 优化 Windows 原生窗口置顶维护，恢复置顶时不抢占键盘焦点。
- 改进 PPT 放映期间悬浮窗的稳定性。

### 构建 (Build)
- 优化 PyInstaller 打包配置。
- 增加 `keyboard` 模块完整资源收集，避免全局快捷键相关依赖遗漏。
- 增加 Windows 键盘钩子后端的构建环境检查。

### [1.6.0] - 2026-11-16

#### 新增
- **自定义尾段敲击起始时间**：新增「敲击起始节点」设置项，开启「临近结束敲击音」后可自由设定剩余 `1 ~ 300` 秒开始每秒触发提示音（默认 10 秒）。
- **放映时暂停全局热键**：新增「放映时暂停全局热键」开关（默认开启）。幻灯片全屏放映期间自动临时移除全局键盘钩子、退出放映后自动恢复，避免全局热键干扰遥控翻页笔（也可按需关闭以在放映中继续使用快捷键）。
- **PPT / WPS 退出放映自动暂停**：完善放映联动闭环，检测到进入全屏放映时自动开始计时，退出放映时自动暂停。

#### 改进
- **重构 PPT / WPS 全屏放映检测**：采用「放映窗口类名 + 进程名与标题关键词 + 进程名与真全屏矩形」三重判定，全面兼容新版 WPS（如 `wpp.exe` / `Qt5QWindowIcon` 无标题关键词场景）及权限受限窗口；引入带 PID 校验的进程名缓存，防止句柄复用导致的误判，并优先检测前台窗口。
- **放映期间手动暂停保护**：优化自动联动逻辑，仅在进入放映边沿触发自动恢复，避免用户在放映途中手动暂停后被轮询重新拉起。
- **焦点防抢夺加固**：为悬浮窗补充 `Qt.WindowDoesNotAcceptFocus` 窗口标志，进一步杜绝悬浮窗显示或交互时抢夺演示窗口焦点。
- **精准热键生命周期管理**：改用句柄精准注销全局热键（`remove_hotkey`），替换原先的全局 `unhook_all`，减少对系统其他键盘事件的干扰。
- **设置界面排版优化**：为设置项副标题启用自动换行，避免较长说明文本显示截断。

#### 修复
- **修复「恢复默认」配置引用问题**：改为将默认配置逐字段深拷贝写回当前配置对象，并完善配置加载时的数值范围与类型容错校验。
- **修复保存设置后放映状态未即时同步的问题**：修改配置并保存后，立即同步当前放映态的热键挂起与自动计时状态。

### [1.4.0] - 2026-08-26

#### 新增
- **自定义提示音效**：支持为“节点预警”与“环节结束”自定义选择本地音频文件（Windows 支持 WAV，macOS 支持 WAV / MP3 / AIFF），内置试听与一键重置功能。
- **窗口位置记忆**：支持自动保存与恢复浮窗在屏幕上的最后摆放位置，重启应用无需重新调整。
- **小时级时间显示**：倒计时/正计时时长超过 1 小时（≥ 3600s）时，自动切换为 `HH:MM:SS` 格式，并自适应扩展文本框宽度防止文字截断。

#### 改进
- **多显示器交互优化**：重构拖拽边界与吸附算法，智能识别当前鼠标所在屏幕（`screenAt`），大幅提升跨屏幕移动与边缘防越界体验。
- **全透明背景支持**：将背景透明度调节范围扩展至 0% ~ 100%，并对完全透明状态下的背景色渲染进行了容错处理。
- **视觉排版与投影**：为环节名称和时间文字增加微投影效果，优化控件垂直居中对齐与间距，文字显示更加立体清晰。

#### 修复
- **修复闪烁结束颜色还原**：优化预警闪烁停止（`stop_flash`）时的颜色刷新逻辑，确保预警状态平稳过渡。

## ✨ 核心特性

- 🎯 **无误差精准计时 (Drift-Free Engine)**
  - 彻底抛弃传统的“累加扣减”计时法。底层采用**绝对系统时间戳锚定**技术，即使你的电脑瞬间卡顿或 UI 线程阻塞，倒计时也绝对不会产生哪怕 1 秒的误差。
- 🎨 **自适应防挤压 UI (Canvas Masking)**
  - 首创的“底层画布隔离”机制确保文字与倒计时数字绝对不会发生重叠。配合 `QPropertyAnimation` 带来极致丝滑的折叠/展开动画。
- 🔄 **多环节无缝流转 & 放映联动**
  - 支持自定义多个流程（如：说课 5 分钟 ➔ 答辩 2 分钟）。可开启**自动流转**模式，倒计时结束自动无缝衔接下一个环节。
  - 支持 **PowerPoint / WPS 全屏放映联动**：进入放映自动开始计时，退出放映自动暂停。
- 🔔 **多线程智能提醒**
  - **原生系统音效**：支持 Windows (`winsound`) 和 macOS (`afplay`)，采用独立守护线程异步播放声音，绝对不卡主界面。支持全局声音一键总控与自定义音效文件。
  - **动态变色闪烁**：可自定义时间节点（如剩余 30 秒变黄，剩余 10 秒变红），并支持自定义尾段倒数敲击音起始节点（1~300 秒）。
- 🛡️ **焦点防抢夺与单例锁**
  - 引入 `Qt.WindowDoesNotAcceptFocus` 与 `Qt.WA_ShowWithoutActivating` 属性，计时器变色闪烁时**绝对处于静默状态**，绝不打断您在 Word/PPT 中的打字流与演示焦点。
  - 工业级 `QSharedMemory` 单例锁，彻底阻止程序多开导致的悬浮条重叠。
- 💾 **原子化保存与便携模式 (Portable)**
  - 配置默认保存在程序同级目录，方便打包放进 U 盘带走！具备**权限智能降级**功能，在 C 盘等无权限目录时自动降级保存至 User 目录，杜绝崩溃。
- ⌨️ **快捷键支持**
  - 支持自定义全局快捷键（播放/暂停、重置、上一环节、下一环节），并支持在幻灯片全屏放映期间自动暂停全局热键，配合翻页笔使用更稳定。
